**Checked with no defect found**
- No ACP, Cursor, ws or connectrpc code remains reachable under `src/`. The `acp` and `cursor` commands, the `--agent` and `--bridge-bin` flags, the `acp`/`cursor`/`agent`/`bridge_bin` settings and stored `api_key` values all fail loudly with a non-zero exit.
- The TUI prewarm thread and the doctor's host detection are gone.
- Claude subscription auto-discovery and the `claude setup-token` `system()` call are removed.
- A custom profile that shadows a builtin still wins, because it is checked first.
- The Makefile, Nix files, `run.sh` and the wasm source lists name no deleted files. The remaining `cursor` strings in those areas belong to the MCP import feature, which is kept.
- libtny's capability mask and transport now advertise OpenAI only.
