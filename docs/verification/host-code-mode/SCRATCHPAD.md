## Design notes

- **Output capture.** Real `print` means output goes through fd 1. The child's
  fds 1 and 2 are one pipe; the *parent* drains it inside its frame waits
  (`tny_exec_aux` in `execution_host.c`) so normal frame waits keep consuming chatty subprocess output; the
  retained-output bound is enforced by the parent. This is not a global
  deadlock proof for arbitrary host programs or callbacks.
  Result = summary line (if error) + output; the output keeps its first bytes
  and last 16 KiB. The head admission uses the new Lean-checked
  `tny_code_output_take`.
- **fd 3.** Already `FD_CLOEXEC`, so `subprocess`/exec children never see it. A
  bare `fork()` child would keep EOF open and could write frames: a
  `pthread_atfork` child handler closes it and sets the stored fd to -1; the
  interpreter layer refuses `tools.call` when `getpid()` differs.
- **Frame interleaving.** With threads, a heap limit can fire off the main
  thread; child frame sends take a mutex so an abort frame never splices into a
  CALL frame.
- **Finalization.** The child `_exit`s after its result (no Python finalizer
  can ask for effects after authority ends), but first runs what an interpreter
  exit would: `threading._shutdown`, `atexit._run_exitfuncs`, stream flush.
  `__main__` is replaced per run instead of being cleared afterwards, which
  had made `__del__` noise appear in captured stderr.
- **sys.executable.** Path discovery with the default program name found the
  host's `python3` on `PATH` (observed: the mise shim). `program_name` is now
  `tny-code-cell` and `sys.executable`/`_base_executable` are set to `""`.
- **Stdlib packaging.** `MODULE_BUILDTYPE=static` + explicit `*_CFLAGS/*_LIBS`
  + `PKG_CONFIG=false` + `py_cv_module_*=n/a` for unpinned modules keeps host
  `-dev` packages out. The frozen table is generated by the build-tree
  interpreter (exact marshal format) as C string literals: 552 modules compile
  in ~2 s. macOS's SDK libffi preference is disabled so the pinned one is used.
- **TLS trust.** Static OpenSSL uses `OPENSSLDIR=/etc/ssl`; a missing
  `/etc/ssl/cert.pem` falls back to the first common bundle via
  `SSL_CERT_FILE` (only when unset). Nix's wrapper already sets it.
- **ADR 0007 amendment.** tny's own provider TLS still dlopens the system
  library; only the embedded runtime links the pinned static OpenSSL.

## Supervisor review and corrections

Shell access was restored and the existing unpushed Opus/high implementation at
`045e4ec` was recovered directly on main. The writer was gracefully interrupted
while waiting on its detached checks; the detached diagnostic inventory and all
prior receipts were preserved. No duplicate implementation was started.

`68861ae` corrects two demonstrated output-protocol failures: invalid UTF-8 lead
bytes followed by continuation bytes, and a long Unicode exception cut in the
middle of a scalar. Both fail on the earlier binary and pass through the real
Responses and Chat wires after repair. The actual lead-byte classifier is
translated from C into Lean; four new specifications and two negative mutations
cover it. Broad byte-partition fixtures use CPython's strict decoder as a
separate reference. This does not prove the whole stream decoder.

The same checkpoint corrects stale model instructions falsely claiming that
sqlite3, ctypes, bz2 and lzma are absent. Actual imports and representative
operations now agree with the captured prompt. Isolated build fixtures include
the new pinned native-library metadata and freezer input; cache identity changes
when any dependency pin changes. Missing metadata is not silently ignored.

`a1676de` fixes a real double-close on output-pipe setup failure, preserves the
original setup errno, and avoids storing a stack reference when atfork setup
fails. The seam test compiles the actual output_pipe function, injects every
setup failure, and rejects ownership/cleanup mutations. No diagnostic is hidden.
The false string-termination warning in length-delimited call framing is removed
by copying a temporary terminator before overwriting it with argument bytes;
wire lengths and the proven frame bounds are unchanged.

Final host operations also cover certificate-verified loopback HTTPS in the
normal integration inventory. The broad original integration run overlapped
relinking and cannot be called a clean final-snapshot pass; its affected job
methods are rechecked against a frozen executable. Full details and all actual
terminal statuses are in evidence.md. No fresh model inference is needed for
these deterministic host and frozen-program checks.
