setup.sh generates trace.ndjson. Each line is one JSON span. A root span has kind=request, parent_id=null, endpoint, and status=ERROR or OK. Each root has exactly one child span with parent_id equal to the root's span_id. Exclusive request time is root duration_us minus its child duration_us. Sum exclusive time only for ERROR roots, grouped by endpoint. failed_count is the number of such roots for the winning endpoint. Child spans may precede their root in the file. Timestamps are irrelevant. ANSWER.txt has exactly three lines as named in the prompt.
