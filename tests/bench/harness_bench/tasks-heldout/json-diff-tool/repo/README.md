jdiff.py LEFT RIGHT compares JSON values and prints a JSON array of changes. Each change has path (JSON Pointer; root is ""), kind ("added", "removed", "changed"), and before/after only where applicable. Object keys are traversed lexically; lists compare by index. Missing keys or indices produce one added/removed entry containing the whole value. Type changes produce one changed entry. bool differs from int. Sort output by path, then kind. Escape "~" as "~0" and "/" as "~1" in path components. --ignore POINTER may repeat and skips that path and descendants. --summary prints {"added":N,"removed":N,"changed":N} instead of the change list. Public function diff_values(left,right,ignored=()) returns the change list. Only Python stdlib.
