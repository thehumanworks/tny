# Code-mode language benchmark

Decision and measurements: [report](../../../docs/verification/code-mode-language/report.md).
The original preregistration is commit `47972c0`; the live harness snapshot is
`7ed5441`. `data/experiment.json` also hashes uncommitted input files at launch.

## Offline verification (no account, no downloads)

```sh
make test-code-mode-language
```

The dedicated CI job, `make test`, and the Nix test derivation run the offline
tests against the actual Python functions. They enumerate the complete acceptance
truth table, promotion Boolean/count boundaries, adjacent large integers, and
negative mutations. No Lean toolchain is needed for the benchmark checks.
The runtime's separate source-linked C proofs still require pinned Lean.

## Rebuild and check native probes

Use Linux, a C compiler compatible with `-flto=auto`, Python **3.14** with its
embedding headers/shared library, `strip`, `ldd`, `bwrap` and `prlimit`. The Python
host intentionally links this version, not a generic unspecified Python binary.
The Python benchmark/analysis utilities require Python 3.10 or newer.

```sh
make bench-code-mode-language CODE_MODE_DOWNLOAD=--download
python3 tests/bench/code_mode/bench_native.py
python3 tests/bench/code_mode/boundaries.py
```

The explicit download flag permits only the pinned official QuickJS 2026-06-04
archive, SHA256 `b376e839b322978313d929fd20663b11ba58b75df5a46c126dd19ea2fa70ad2a`.
A missing/mismatched archive fails without implicit substitution. No dependency
is added to the shipped Tny runtime. All three adapters share `host.c` virtual
capabilities; Lua links the measured runtime unchanged: since ADR 0179 that is
the benchmark-only copy in `lua_runtime/`, byte-identical to PR #197's
`src/core/code_runtime.c` and `third_party/lua/`.

The effect runner requires bubblewrap and fails without it. It does not expose
host HOME/workspace, inherited credentials or network access. Its read-only
mounts contain only the chosen executable and interpreter/system dependencies.
The common process deadline is two seconds; each process has a 512 MiB address-
space limit, while Lua/QuickJS additionally have a 16 MiB interpreter heap limit.
CPython's restricted globals are not presented as a standalone sandbox.

## Live experiment (explicit account usage)

First verify the existing Codex CLI reports a ChatGPT login. The runner does not
read, copy, refresh or print credentials; the normal CLI owns authentication.
It always requests `gpt-6-luna` and low effort, with user config ignored, an
external temporary cwd, a code-only output schema, and no allowed generation-time
tool use. Exactly 108 first generations are planned, with at most one repair per
failure. A generation failure leaves the cohort explicitly incomplete.

```sh
codex login status
python3 tests/bench/code_mode/run.py --live --output build/code-mode-bench/new-live
python3 tests/bench/code_mode/analyze.py --input build/code-mode-bench/new-live/samples.json
python3 tests/bench/code_mode/audit.py --directory build/code-mode-bench/new-live --replay
```

Output directories must be new; successful samples are never silently overwritten
or rerun to select a favorable outcome. Keep all first-attempt failures. New
experiments should use new held-out families rather than tuning the published
corpus. Do not compare candidate trials generated by a different model, effort,
tool interface, hidden fixture distribution or repair budget.

`export.py` exports the default completed `build/code-mode-bench/live` run and
its audit/measurement files. It never includes authentication files. The raw
generation archive contains synthetic prompts, code, CLI events and usage, not
user workspace contents. A replay independently checks effects and reconciles
raw code/usage; it is not a second independent author of the task oracle.

## Verification boundary

`policy.py` contains the actual acceptance/promotion predicates used by scoring
and analysis. `test_benchmark.py` calls those functions directly, replays the
recorded retention decisions, and checks that guard removal, comparison reversal,
strictness changes and floating-point rounding are detected. These are finite
regression checks; they do not establish an all-integer theorem, stochastic
inference quality, interpreter correctness or OS isolation.

[ADR 0188](../../../docs/adr/0188-focused-verification-maintenance.md) replaces
the benchmark-only Lean translators and proofs with these checks. The original
preregistered policies and evidence are unchanged; historical proof source and
results remain in Git history.
