# tnyboard

Standalone Python 3.9+ local cooperative ticket boards. No runtime dependencies.

- [Usage, storage and trust model](docs/README.md)
- [Exact RPC/HTTP/Python API and dispatch contract](docs/api.md)
- [JSON schemas](schemas/README.md)
- [Verification evidence](docs/evidence.md)

From the parent directory: `python3 -m tnyboard --help`.
Install: `python3 -m pip install ./tnyboard`.
Verify: `make -C tnyboard check`.
